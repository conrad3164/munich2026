# Munich 2026

Carnet de voyage familial, protégé par un compte unique.

Le programme, les notes et les billets vivent dans Firestore et ne sont lisibles
qu'une fois connecté. Rien de sensible dans ce dépôt : aucun identifiant lisible,
aucune adresse e-mail.
